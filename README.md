# Java Atlas

Русскоязычный интерактивный курс и шпаргалка на основе материалов этой папки. Структура следует 11 листам файла `Java Подготовка к интервью.xlsx`. Сайт показывает вопросы, исходные ответы, конспекты PDF/DOCX, карточки самопроверки и чеклист для интервью.

## Запуск

Нужны Python 3 и `pdftotext` (пакет `poppler-utils`). Дополнительные Python- или npm-библиотеки не нужны.

```bash
python3 build.py
python3 server.py
```

Откройте <http://localhost:8000>. Для другого порта: `python3 server.py --port 8080`. После изменения исходного Excel/PDF/DOCX повторите `python3 build.py`, затем перезагрузите страницу. Запускайте сайт через `server.py`: он отдаёт оригиналы по `/assets/` прямо из исходных папок, не создавая вторые копии документов.

## Docker: запуск готового образа

Docker-образ содержит сайт, сгенерированные данные и все исходные PDF/DOCX/XLSX. Для быстрого запуска скачайте **только `compose.yaml`** на машину с Docker и выполните в каталоге этого файла:

```bash
docker compose up -d
```

Файл скачивает `aidarchik/java-atlas:latest` из Docker Hub и публикует порт 8000. Откройте <http://localhost:8000> локально или `http://IP_СЕРВЕРА:8000` с другого устройства (на сервере должен быть открыт порт 8000). Никакие PDF, Excel и DOCX переносить на сервер не нужно. Для обновления до свежей версии образа повторите `docker compose up -d`.

Если нужно самостоятельно собрать образ из исходной папки, выполните:

```bash
docker compose -f compose.build.yaml up --build -d
```

В `compose.build.yaml` порт привязан к `127.0.0.1` для локального тестирования. Во время сборки PDF обрабатываются `pdftotext`; в готовом образе эта утилита не нужна. Также можно собрать и запустить образ вручную:

```bash
docker build -t java-atlas:latest .
docker run -d --name java-atlas -p 8000:8000 --restart unless-stopped java-atlas:latest
```

В этом варианте контейнер доступен по `http://IP_СЕРВЕРА:8000`, если у сервера есть публичный IP и входящий TCP-порт 8000 открыт. Сам по себе образ не предоставляет публичный IP или домен: контейнер нужно запустить на доступном из интернета сервере. Для переноса уже собранного образа на другую машину можно выполнить `docker save java-atlas:latest | gzip > java-atlas.tar.gz`, перенести архив и загрузить его командой `gunzip -c java-atlas.tar.gz | docker load`.

### Публикация автономного образа в Docker Hub

Образ уже содержит **все файлы курса**: Excel, PDF, DOCX, сайт и готовый индекс поиска. После публикации на других компьютерах папка проекта и `build.py` не нужны.

На компьютере с исходными материалами выполните (репозиторий Docker Hub — `aidarchik/java-atlas`):

```bash
docker login
docker build -t aidarchik/java-atlas:latest .
docker push aidarchik/java-atlas:latest
```

Если Docker сообщает `permission denied` при обращении к `/var/run/docker.sock`, выполните команды `docker build` и `docker push` с `sudo` (для `docker login` тогда тоже используйте `sudo docker login`, чтобы учётные данные сохранились для того же пользователя).

**На любой другой машине с Docker** достаточно одной команды, без копирования материалов:

```bash
docker run -d --name java-atlas --restart unless-stopped -p 8000:8000 aidarchik/java-atlas:latest
```

Docker автоматически скачает образ из Docker Hub. Для остановки: `docker stop java-atlas`. Изменения в файлах после сборки не попадают в опубликованный образ автоматически: его нужно собрать и отправить в Docker Hub повторно.

## Публикация в интернете с HTTPS

1. Подготовьте сервер с публичным IP и Docker Compose. Перенесите на него папку проекта целиком, включая материалы, `Dockerfile`, `Caddyfile` и `compose.public.yaml`.
2. Укажите A-запись домена на IPv4-адрес сервера (и AAAA-запись, если настроен IPv6). Разрешите входящие TCP 80/443 и UDP 443 в настройках сервера/облака.
3. На сервере в папке проекта запустите:

```bash
ATLAS_DOMAIN=java.example.com docker compose -f compose.public.yaml up --build -d
```

Замените `java.example.com` своим доменом. После обновления DNS сайт откроется по `https://java.example.com`. Caddy автоматически получает и обновляет TLS-сертификат; его данные сохраняются в Docker volumes. Статус и логи: `docker compose -f compose.public.yaml ps` и `docker compose -f compose.public.yaml logs -f`.

Чтобы опубликовать изменения материалов, обновите файлы на сервере и снова запустите ту же команду с `--build`. Прогресс, заметки и избранное сохраняются в браузере посетителя, поэтому они не синхронизируются между устройствами.

## Как устроены данные

- `build.py` читает XLSX и DOCX средствами Python, PDF — через `pdftotext`. Результат: `site/data.json` (генерируемый файл).
- Заголовки без ответов на листах Core-1 и Core-2 используются как группы, а не как вопросы; остальные вопросы без ответа видны с явной пометкой.
- На карточке показаны координаты исходной ячейки Excel, исходный ответ и документы раздела. DOCX и PDF также доступны как извлечённый текст в библиотеке; схемы и таблицы лучше сверять с оригиналом PDF.
- Если формулировка вопроса найдена в тексте PDF, карточка показывает ссылку на найденную страницу. Это автоматическая привязка по тексту; для остальных вопросов доступны документы раздела.
- Отметки изученного, избранное, повторение, заметки и черновики задач сохраняются только в `localStorage` браузера. Пять быстрых таблиц доступны в разделе «Быстрые таблицы». Для запуска Java-кода на сервере или в браузере окружение не создаётся.

## Проверка

```bash
python3 -m py_compile build.py server.py
node --check site/app.js
```

Проверьте главную, поиск, конкретный вопрос, библиотеку и оригиналы, практику и сохранение заметки после обновления страницы.
